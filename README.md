# 🍔 Dad's Burger · Cardápio Digital & Delivery

Cardápio digital responsivo e moderno para o **Dad's Burger** (Porto Alegre - RS), com pedidos diretos via WhatsApp, carrossel de upsell de refrigerantes, reserva de mesas e localização integrada.

🌐 **Demo ao vivo (GitHub Pages):** [https://theboyxd.github.io/dads-burger/](https://theboyxd.github.io/dads-burger/)

---

## ✨ Funcionalidades

- **Cardápio Completo (47+ Itens):** Combos na Caixa, Hambúrgueres Artesanais, Porções crocantes e Bebidas geladas com fotos e descrições oficiais.
- **Upsell Inteligente de Refrigerantes:** Ao adicionar hambúrgueres ou porções sem bebida, o carrinho destaca automaticamente opções geladas (Coca-Cola 350ml, Guaraná Fruki Lata, Coca 2L, Sprite, Fanta, etc.).
- **Carrinho e Checkout WhatsApp:** Cálculo automático de totais, só entrega, pagamento 100% online (sem retirada nem dinheiro) e envio formatado da mensagem para o WhatsApp do restaurante.
- **Reserva de Mesas:** Formulário integrado para agendamento de data, horário e número de pessoas.
- **Localização & Horários:** Integração com Google Maps, status de "Aberto agora" e cálculo de rotas.
- **Expo-Glass Navigation:** Barra de navegação inferior estilo Liquid Glass (iOS/Android) com efeito de vidro e feedback tátil.
- **100% Responsivo:** Otimizado para celular e desktop.

## 🚀 Como Executar

### Opção 1: Static / Navegador (Direto)
Basta abrir o arquivo `index.html` em qualquer navegador. Não requer instalação ou servidor backend.

### Opção 2: Vite + React / TypeScript (Dev Server)
Se preferir rodar a versão componentizada:
```bash
npm install
npm run dev
```

### Opção 3: Servidor completo (painel, pedidos e pagamentos)
O painel do restaurante, as fotos enviadas, os pedidos e o Mercado Pago precisam do servidor (`npm start`), que o GitHub Pages não roda.
Para colocar o site de verdade no ar, numa hospedagem com disco persistente, siga o **[DEPLOY.md](DEPLOY.md)**.
